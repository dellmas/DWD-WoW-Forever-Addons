WoW Forever Addon Pack v1.0.7 - CurseForge recognition
For WoW Forever 1.60.1 (interface 16001).

27 addon folders are supplied by 21 CurseForge projects. Bundled modules appear
under their parent project in CurseForge; they do not all have separate rows.
All addon files are copied unchanged from their corresponding release archives.

INSTALL AND ENABLE CURSEFORGE UPDATE TRACKING
1. Close WoW. Back up your existing Interface/AddOns and WTF folders.
2. For each supplied addon, move its previous folder out of Interface/AddOns
   into a backup directory, then copy the clean folder from this ZIP's AddOns.
   Replacing whole folders avoids leftover beta files changing recognition.
3. If present, also archive Bartender4_Forever, DWD_Profiles_Recovery, and
   DWD_UpdaterStatus outside AddOns. The first is replaced by official Bartender4;
   the other two are legacy helpers omitted from this CurseForge-managed pack.
   Do not enable both Bartender copies. The old beta Bartender layout uses a
   different database and needs a separate layout migration before switching.
4. Leave your WTF folder alone. This ZIP contains no WTF/account files or saved
   profiles and does not migrate settings. Existing Main1/Main2 profiles in your
   own SavedVariables are retained; no personal layouts are supplied here.
5. In CurseForge, select World of Warcraft and the Forever installation.
   Use the three-dot menu beside Run Game > Scan addons folder > Scan.
6. Check My Addons. This exact collection was recognized as 21 projects on the
   source installation. Approval, indexing, app version, or later release changes
   can affect detection on another PC. Refresh or rescan after processing completes.
7. Reopen WoW. Enable both Questie and QuestieDB, plus desired addons.

If the old DWD desktop updater is enabled, use its Disable Auto Updates button
when moving to CurseForge management, so two tools do not replace the same folders.
CurseForge manages updates outside WoW. Restart or reload WoW after updates as
required by the addon; a reload cannot discover a newly added addon folder.

No personal settings, character data, error logs, account folders, or filesystem
junctions are included. Original author and license notices are retained.
