DWD Bagnon Helper - Forever 1.0.0-forever.1
Requires Bagnon. Designed against Bagnon / BagBrother 12.1.8 on Forever 1.60.1.

Open inventory normally. It stays open until you click its close X.
Map maximization, Escape, bag hotkeys/backpack buttons, merchant/character
window changes, combat/vehicle events, and other normal hide requests cannot
close it. Bag hotkeys can still open a closed inventory. The X stays available
even if the selected Bagnon skin normally hides it.

Only inventory is guarded. Bank, guild bank, void storage, other windows and
the game menu keep their normal behavior. Global UI hiding, loading screens,
logout and restarting/reloading the UI are controlled by WoW. If a protected
native hide bypasses the guard in combat, restoration waits until combat ends.

No settings or counts are changed or saved. Bagnon and BagBrother files remain
unmodified and can update normally. Disable this helper and reload to restore
Bagnon's normal close behavior. /dwdbags prints its status.

Install DWD_BagnonHelper-Forever in Interface/AddOns. Restart WoW for a newly
installed addon folder to appear. For later updates of the same folder, reload.
