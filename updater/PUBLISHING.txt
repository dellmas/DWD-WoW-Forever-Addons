Legacy feed maintenance

Every latest release retains DWD-Updates.json and DWD-Only-Addons.zip for older
updater installations. The manifest release must equal the GitHub tag.
The current feed contains only MobCount, Party XP, and Tooltip Mover.
Never package the retired DWD Profiles, Early Loader, or recovery helper.
The source allowlist excludes them, and all historical public feeds and ZIPs
have been cleaned. Existing binaries also accept the smaller supported subset.

Build feeds from supported addon folders using build_feed.py. Verify manifest
checksums and exact ZIP membership before publishing. Do not include saved
settings, WTF, account data, private profile seeds, or filesystem junctions.
The full pack provenance is recorded in CURSEFORGE-PROJECTS.json.
