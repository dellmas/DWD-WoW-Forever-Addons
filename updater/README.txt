LEGACY DWD DESKTOP UPDATER

Disable Auto Updates before switching to CurseForge. The source remains in
the repository for existing installations. The compatibility feed covers only
!DWD_Profiles_Loader, DWD_Profiles, DWD_MobCount, DWD_PartyXP_Forever, and
